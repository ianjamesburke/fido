Why Fido

01

Lightning Fast

Terminal-native. Zero overhead. Renders in microseconds.

02

Keyboard-Driven

Every action on a keybind. Vim-style navigation throughout.

03

Privacy-First

No algorithms. No ads. No data collection. Pure signal.

04

Built with Rust

Memory-safe. Single binary. Ships and runs everywhere.

Features

  • Direct messaging
  • Follow hashtags
  • Follow users
  • Upvote / downvote posts
  • Customizable color schemes
  • Configurable sorting and display

Frontend Rust + Ratatui
